# Simulado 1 — Layout com tabelas

Exercício de layout em HTML e CSS, feito no início do curso técnico. A página foi construída inteiramente com uma tabela, com células mescladas por `colspan` e `rowspan`, para reproduzir um layout de várias colunas sem usar as ferramentas de grid que vieram depois.

## O que pratiquei

- Mesclagem de células com `colspan` e `rowspan` para montar uma estrutura de colunas.
- Controle de dimensões de célula por CSS, com identificadores por linha e coluna.
- Espaçamento e alinhamento dentro de uma grade rígida.
- Ligação entre estrutura de documento, texto e imagem.

## Como abrir

Abra o `index.html` no navegador. Não há build nem instalação.

## Observação

O texto da página é um *Lorem ipsum*, porque o exercício era sobre a estrutura, não sobre o conteúdo. Hoje o mesmo layout seria feito com CSS Grid, em muito menos código e com o resultado se adaptando a telas de tamanhos diferentes. Mantive o arquivo como registro da etapa.
